Integração com o PNCP e sistemas de licitação

Três camadas distintas: dados públicos do governo, matching comercial LicitaFit, e a UI do ERP / Dashboard onde a equipe decide.

O LicitaFit não é o PNCP e não substitui o Manual de Integração oficial destinado a órgãos e plataformas que alimentam o portal. Documentação oficial: Manual de Integração do PNCP.

1. Camada governo (PNCP / dados abertos)

  • Consulta pública e dados abertos descritos em PNCP em Dados Abertos.
  • APIs de manutenção (inserir/retificar dados no PNCP) exigem credenciamento junto ao Ministério da Gestão (MGI) e são para plataformas/órgãos que publicam atos, não para “matching de catálogo” de fornecedor.
  • Contatos oficiais citados pelo governo incluem o Portal de Serviços do MGI e o telefone 0800 978 9001 (verifique indisponibilidades nos comunicados do PNCP).

2. Camada LicitaFit (matching comercial)

O LicitaFit consome divulgações públicas e cruza com o catálogo do cliente. Entrega oportunidades, status de requisitos e eventos (webhooks) para o parceiro. Detalhe de produto: integração API LicitaFit e API oficial PNCP vs matching comercial.

3. Camada ERP / Dashboard

  • Parceiro de software: embute a API no ERP/AFV (como embutir).
  • Equipe de licitação: usa o Dashboard (como usar).

Em ambos os casos, a decisão de avançar na oportunidade é humana. Status needs_review existe para isso.

O que não misturar

  • Credencial de plataforma que publica no PNCP ≠ chave da API LicitaFit.
  • Feed bruto de consultas públicas ≠ produto de matching com SKUs do cliente.
  • Portal de disputa / pregão eletrônico ≠ PNCP (divulgação).

Perguntas frequentes

Preciso credenciar no MGI para usar o LicitaFit?

Para consumir matching comercial, não: você integra a API ou o Dashboard LicitaFit. Credenciamento MGI/PNCP aplica-se a quem alimenta o portal como plataforma/órgão (ver Manual oficial).

O LicitaFit publica editais no PNCP?

Não. O LicitaFit lê divulgações públicas e cruza com catálogo. Publicação no PNCP é responsabilidade dos órgãos/plataformas credenciadas.

Onde fica a documentação oficial de integração ao PNCP?

No Manual de Integração: https://pncp.gov.br/manual/pt-br/latest/
