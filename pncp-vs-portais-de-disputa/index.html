PNCP vs Compras.gov.br / portais de disputa

O PNCP é o portal de divulgação centralizada dos atos da Lei nº 14.133/2021 (art. 174). Compras.gov.br / ComprasNet e outros portais de disputa (ex.: Licitar Digital, BLL, BNC) são onde muitas compras são operadas. Publicar no PNCP não substitui o sistema de origem. Isto é contexto de mercado (não um diferencial exclusivo do LicitaFit).

Definição oficial do PNCP: gov.br/pncp. Guia curto: o que é o PNCP.

Contraste rápido

Peça Papel típico Nota para ERP / distribuidor

Compras.gov.br / ComprasNet Ecossistema federal de compras (operação, disputa, dados abertos, catálogo) Complementa o federal; não substitui o PNCP como repositório multi-esfera
Outros portais de disputa Onde o pregão / disputa ocorre (ex.: Licitar Digital, BLL, BNC, Licitações-e) Dados públicos costumam apontar o link do sistema de origem

Exemplos de portais são ilustrativos (sem ranking nem cobertura inventada). Dados abertos Compras.gov.br: portal de dados abertos.

Por que os dois conceitos importam no ERP

  • Descobrir / monitorar oportunidades a partir de dados públicos (PNCP e correlatos).
  • Disputar no portal certo (o link ao sistema de origem não some porque houve publicação no PNCP).
  • Matching de catálogo responde “estes SKUs merecem revisão?” (não “em qual URL clicar para lance”).

Honestidade sobre o LicitaFit

Esta página é educacional. Qualquer time de compras públicas precisa distinguir divulgação e disputa. O que o LicitaFit vende é matching catálogo ↔ item e alertas de impacto no ERP (não “ser o PNCP” nem substituir ComprasNet). Feed bruto versus produto de matching: comparativo.

Perguntas frequentes

PNCP e Compras.gov.br são a mesma coisa?

Não. O PNCP centraliza a divulgação dos atos da Lei 14.133. Compras.gov.br / ComprasNet é o ecossistema federal (operação, disputa, dados abertos). Outros entes usam outros portais de disputa.

Publicar no PNCP elimina o portal de disputa?

Não. A divulgação no PNCP não substitui o sistema de origem onde a compra é operada. Os dados públicos costumam trazer o link ao sistema de origem.

Isso é um diferencial exclusivo do LicitaFit?

Não. É contexto de mercado. O diferencial do produto é o matching do catálogo do distribuidor com oportunidades públicas no ERP.
