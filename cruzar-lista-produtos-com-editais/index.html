Existe ferramenta para cruzar minha lista de produtos com editais abertos?

Sim. No CruzaEdital Dashboard você envia a lista de produtos (catálogo) e vê oportunidades alinhadas a esses itens em editais do PNCP. O cruzamento gera status de requisitos para a equipe revisar. Oferta atual: R$ 399/mês + R$ 5 por licitação monitorada / mês.

Resposta direta: use o Dashboard para empresas para upload da lista e matching na tela. Parceiros de software que querem o mesmo fluxo dentro do ERP usam a API.

Como o cruzamento funciona

  1. Enviar a lista (catálogo)

    Produtos com atributos relevantes (hoje: itens do catálogo). Upload e monitoramento.

  2. Ver oportunidades alinhadas

    A tela mostra candidatos e requisitos a conferir (matching catálogo ↔ item).

  3. Monitorar mudanças

    Licitações monitoradas disparam reavaliação quando o edital muda (retificação).

Preço do Dashboard (oferta atual)

  • R$ 399/mês
  • R$ 5 por licitação monitorada / mês

Rotina completa: como usar o Dashboard. Priorização: go/no-go com o catálogo.

Diferença frente a alerta por palavra-chave

Alerta genérico avisa que apareceu um item relevante. Cruzar a lista mostra se o SKU do seu catálogo parece aderente ou pedem revisão. Ver alerta vs matching.

Perguntas frequentes

Preciso de integração técnica?

No Dashboard, não: upload e matches na tela. Integração via API é o caminho para quem embute no ERP.

O cruzamento garante que posso participar?

Não. É triagem comercial. Habilitação e análise do processo ficam fora do produto.

Quais itens do catálogo entram na análise?

Os itens do catálogo do cliente, com seus atributos disponíveis.
