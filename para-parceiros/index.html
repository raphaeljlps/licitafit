Parceiros de software

API LicitaFit para embutir matching no seu produto

Para fundadores e líderes de produto de ERP, comercial/AFV e verticais de TI cujos clientes atuam em compras públicas. Vocês continuam donos da interface e do relacionamento; nós entregamos matching de catálogo a oportunidades do PNCP.

Para quem é a API

O usuário final continua sendo a equipe comercial ou de vendas ao governo do distribuidor (a feature fica embutida no software do parceiro).

ERP de distribuição / atacado

Feature “oportunidades de governo alinhadas ao catálogo” no ERP que o distribuidor já usa (sem o parceiro manter pipeline próprio de dados do PNCP).

Software comercial / AFV

Vendedores já trabalham catálogo e orçamentos no app de força de vendas; somamos triagem de oportunidades públicas ligada aos SKUs do cliente.

Verticais de informática / eletrônicos

Softwares feitos para distribuidores com serial, RMA e estoque que vendem hardware B2G (com foco inicial em notebooks e monitores).

Compras públicas no stack

Complemento opcional: matching consciente de catálogo e alertas de mudança (sem substituir portais de disputa ou módulos de gestão já existentes).

Como a API funciona

Três peças. Uma integração. O software do parceiro continua dono da UI.

  1. Ingestão de compras públicas

    Coleta registros relevantes no PNCP, guarda identificadores e versões, e revisita oportunidades monitoradas quando há alteração.

  2. Matching catálogo ↔ item

    Compara produtos do cliente com itens do edital, inspeciona documentos selecionados e devolve explicações. Requisitos ilegíveis ficam em aberto.

  3. API de parceiro

    Chaves de API, upload de catálogo, uso, logs de webhook e correção de matches (sem o parceiro manter pipeline próprio de dados públicos).

Endpoints

POST /v1/catalogs
PUT  /v1/catalogs/{id}/products
GET  /v1/catalogs/{id}/opportunities
POST /v1/opportunities/{id}/feedback
POST /v1/webhook-endpoints
