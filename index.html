Qualificação ligada ao catálogo do cliente

O LicitaFit ajuda o ERP a mostrar quais oportunidades públicas fazem sentido para os produtos que o distribuidor já vende — com contexto para a equipe revisar.

Oportunidades que merecem olhar

Filtra ruído e devolve um conjunto curto, com motivos ligados a produtos reais do catálogo.

Requisitos com status explícito

Matched, conflito ou unknown. Informação faltando vira revisão — nunca chute de elegibilidade.

Monitoramento de mudanças

Quando o edital, o item ou o documento muda, o parceiro recebe alerta com o impacto no matching anterior.

Como funciona

Três peças. Uma integração. O ERP continua dono da interface e do relacionamento com o cliente.

  1. Ingestão de compras públicas

    Coleta registros relevantes no PNCP, guarda identificadores e versões, e revisita oportunidades monitoradas quando há alteração.

  2. Matching catálogo ↔ item

    Compara produtos do cliente com itens do edital, inspeciona documentos selecionados e devolve explicações. Requisitos ilegíveis ficam em aberto.

  3. API de parceiro

    Chaves de API, upload de catálogo, uso, logs de webhook e correção de matches — sem o parceiro manter pipeline próprio de dados públicos.

Para quem é o LicitaFit

Vendemos para fundadores e product leads de ERP e software comercial que atendem distribuidores de TI com atuação em compras públicas. O usuário final é quem decide quais editais merecem atenção.

Para o ERP

Uma feature paga — “Oportunidades de governo alinhadas ao catálogo” — sem manter pipeline de dados públicos nem produto próprio de análise de documentos.

Para a Launchbase

Um produto de API reutilizável, com contrato de parceiro — em vez de um sistema sob medida por distribuidor.

Perguntas frequentes

O que o LicitaFit faz?

É uma API para ERP e software comercial: o parceiro envia o catálogo do distribuidor de TI e recebe oportunidades públicas relevantes, produtos que batem potencialmente, requisitos a conferir e alertas quando o edital muda.

O matching substitui parecer jurídico ou garantia de habilitação?

Não. O LicitaFit é apoio à decisão comercial. Resultados usam status como matched, conflito ou unknown e qualificações como needs_review — não constituem parecer jurídico nem garantia de habilitação.

Para quem é o produto?

Para founders e product leads de ERP que atendem distribuidores de TI em compras públicas. O usuário final típico é a equipe comercial que decide quais editais merecem atenção.

Quais categorias o foco atual cobre?

O foco declarado é notebooks e monitores — categorias com especificação técnica modelável para matching e revisão humana.
