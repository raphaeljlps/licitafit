Perguntas frequentes

O que o CruzaEdital faz?

Duas ofertas em caminhos separados: (1) API para parceiros de software (veja Para parceiros); (2) CruzaEdital Dashboard (veja Para empresas). Em ambos: oportunidades relevantes, requisitos a conferir e alertas quando o edital muda.

O matching aprova uma oportunidade?

Não. O CruzaEdital é triagem comercial. Resultados usam status como matched, conflito ou unknown e qualificações como needs_review (não constituem conferência do edital e da documentação). Leia os limites do matching.

Para quem é o produto?

Parceiros de software: Perfil e oferta API. Equipes que trabalham com licitação: Dashboard. O produto trabalha com itens do catálogo em geral.

Quais itens do catálogo podem ser analisados?

Itens do catálogo com atributos técnicos disponíveis para matching e revisão humana.
