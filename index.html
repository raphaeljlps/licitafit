Qualificação ligada ao catálogo do cliente

O LicitaFit ajuda o ERP a mostrar quais oportunidades públicas fazem sentido para os produtos que o distribuidor já vende — com contexto para a equipe revisar.

Oportunidades que merecem olhar

Filtra ruído e devolve um conjunto curto, com motivos ligados a produtos reais do catálogo.

Requisitos com status explícito

Matched, conflito ou unknown. Informação faltando vira revisão — nunca chute de elegibilidade.

Monitoramento de mudanças

Quando o edital, o item ou o documento muda, o parceiro recebe alerta com o impacto no matching anterior.

Como funciona

Três peças. Uma integração. O software do parceiro continua dono da interface e do relacionamento com o cliente.

  1. Ingestão de compras públicas

    Coleta registros relevantes no PNCP, guarda identificadores e versões, e revisita oportunidades monitoradas quando há alteração.

  2. Matching catálogo ↔ item

    Compara produtos do cliente com itens do edital, inspeciona documentos selecionados e devolve explicações. Requisitos ilegíveis ficam em aberto.

  3. API de parceiro

    Chaves de API, upload de catálogo, uso, logs de webhook e correção de matches — sem o parceiro manter pipeline próprio de dados públicos.

Endpoints

Envie o catálogo do seu cliente. Devolvemos oportunidades relevantes, os produtos que batem, requisitos a conferir e alertas quando algo muda.

Para quem é o LicitaFit

Duas frentes comerciais claras: parceiros de software (B2B2B), que embutem a API no produto deles, e equipes que trabalham com licitação (B2B), que terão o LicitaFit Dashboard para operar o matching diretamente.

Parceiros de software (B2B2B)

Para fundadores e product leads de ERP, comercial/AFV e verticais de distribuição de TI cujos clientes atuam em compras públicas. A API fica embutida no software do parceiro; o usuário final continua sendo a equipe comercial ou de vendas ao governo do distribuidor.

ERP de distribuição / atacado

Feature “oportunidades de governo alinhadas ao catálogo” no ERP que o distribuidor já usa — sem o parceiro manter pipeline próprio de dados do PNCP.

Software comercial / AFV

Vendedores já trabalham catálogo e orçamentos no app de força de vendas; somamos triagem de oportunidades públicas ligada aos SKUs do cliente.

Sistemas verticais de informática / eletrônicos

Softwares feitos para distribuidores com serial, RMA e estoque que vendem hardware B2G — com foco inicial em notebooks e monitores.

Produtos de compras públicas já no stack

Complemento opcional: matching consciente de catálogo e alertas de mudança — sem substituir portais de disputa ou módulos de gestão de licitação já existentes.

Equipes que trabalham com licitação (B2B)

Para distribuidores, equipes de vendas ao governo e empresas que respondem editais — quem opera a licitação no dia a dia, não só vendedores de software. Teremos o LicitaFit Dashboard (oferta em preparação): uso direto, sem depender de um ERP parceiro.

Upload e gestão de catálogo

Envie a lista de produtos, revise e atualize o catálogo no dashboard — o matching usa os SKUs que a equipe já vende.

Resultados de matching na tela

Veja oportunidades alinhadas ao catálogo, com requisitos matched, em conflito ou unknown — para a equipe priorizar o que merece revisão.

Alertas de mudança

Quando o edital ou o item muda, o dashboard sinaliza o impacto no matching anterior — apoio à decisão comercial, não parecer jurídico.

Perguntas frequentes

O que o LicitaFit faz?

Duas ofertas: (1) API para parceiros de software (ERP, comercial/AFV) embutirem matching de catálogo no produto deles; (2) LicitaFit Dashboard (em preparação) para equipes que operam licitação — upload de catálogo, revisão de matches e alertas, sem depender de um ERP parceiro. Em ambos os casos: oportunidades relevantes, requisitos a conferir e alertas quando o edital muda.

O matching substitui parecer jurídico ou garantia de habilitação?

Não. O LicitaFit é apoio à decisão comercial. Resultados usam status como matched, conflito ou unknown e qualificações como needs_review — não constituem parecer jurídico nem garantia de habilitação. Leia os limites do matching e o guia de matching catálogo ↔ item.

Para quem é o produto?

Parceiros de software (B2B2B): founders e product leads de ERP de distribuição/atacado, software comercial e AFV, sistemas verticais de informática/eletrônicos e produtos de compras públicas já no stack. Equipes que trabalham com licitação (B2B): distribuidores, vendas ao governo e empresas que respondem editais e querem o dashboard direto.

Qual a diferença entre a API parceiro e o LicitaFit Dashboard?

A API para parceiros de software cobra por uso: R$ 50 por 1.000 requests (mínimo R$ 490/mês) e R$ 1,90 por licitação monitorada / mês — para quem embute o matching no ERP ou AFV do cliente. O LicitaFit Dashboard é um plano próprio, em preparação, para equipes que operam licitação usarem upload de catálogo e resultados diretamente — preço diferente da API, sob consulta.
