Perguntas frequentes

O que o LicitaFit faz?

Duas ofertas em caminhos separados: (1) API para parceiros de software — veja Para parceiros; (2) LicitaFit Dashboard — veja Para empresas. Em ambos: oportunidades relevantes, requisitos a conferir e alertas quando o edital muda.

O matching substitui parecer jurídico ou garantia de habilitação?

Não. O LicitaFit é apoio à decisão comercial. Resultados usam status como matched, conflito ou unknown e qualificações como needs_review — não constituem parecer jurídico nem garantia de habilitação. Leia os limites do matching.

Para quem é o produto?

Parceiros de software (B2B2B): ICP e oferta API. Equipes que trabalham com licitação (B2B): Dashboard. Foco atual: notebooks e monitores.

Qual a diferença entre a API parceiro e o LicitaFit Dashboard?

A API cobra por uso (R$ 50 / 1.000 requests, mín. R$ 490/mês; R$ 1,90 / licitação monitorada) — detalhes. O Dashboard usa assinatura de R$ 399/mês + R$ 5 por licitação monitorada / mês, sem cobrança por request. O monitoramento é mais alto que os R$ 1,90 da API; detalhes.

Quais categorias o foco atual cobre?

Notebooks e monitores — categorias com especificação técnica modelável para matching e revisão humana.
