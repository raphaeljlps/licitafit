Cobrança API: requests e monitoramento

Para founders e product leads que vão empacotar a feature no software parceiro: a API cobra por uso de requests (com mínimo mensal) e por licitação monitorada. Esta página explica o modelo publicado (sem inventar faixas de volume).

Fonte de preço: oferta para parceiros (API). Não inventamos métricas de volume nem faixas intermediárias.

Duas linhas de cobrança

API · Parceiros de software

R$ 50 por 1.000 requests

Mínimo R$ 490/mês

Monitoramento: R$ 1,90 por licitação monitorada / mês

Requests (uso da API)

A linha de requests cobre o uso da API no software do parceiro (criar/atualizar catálogo, listar oportunidades, enviar feedback, operar webhooks, conforme o fluxo publicado). O mínimo mensal de R$ 490 aplica-se ao plano API parceiro.

  • Preço unitário: R$ 50 / 1.000 requests
  • Piso mensal: R$ 490
  • Empacote a feature no ERP sem inventar “pacotes de volume” não publicados

Endpoints de referência: integração API.

Monitoramento por licitação

R$ 1,90 por licitação monitorada / mês cobre o acompanhamento de mudanças (edital ou item) e o sinal para reavaliar o matching anterior.

  • Útil quando a oportunidade permanece na fila comercial
  • Conecta com alertas via webhook no ERP do parceiro
  • Não congela habilitação: mudança pede revisão humana

Contexto de produto: retificação e impacto no matching.

Como empacotar na feature do parceiro

  • Separe mentalmente: uso da API (requests) vs. oportunidades sob acompanhamento (monitoramento)
  • O preço público desta página é o da API para o software parceiro
  • O valor cobrado do end-user pelo parceiro é decisão comercial do parceiro (não inventamos preço de end-user aqui)
  • Na UI, mantenha disclaimer de apoio comercial (não parecer jurídico)

Equipes que usam matching direto (sem ERP parceiro) têm oferta própria no LicitaFit Dashboard.

Perguntas frequentes

Quanto custa a API LicitaFit para parceiros?

R$ 50 por 1.000 requests, com mínimo de R$ 490/mês, e R$ 1,90 por licitação monitorada / mês.

O que é cobrança por licitação monitorada?

Linha de preço para manter oportunidades sob acompanhamento de mudanças no edital ou no item, com reavaliação do matching quando há alteração.

Esta página define o preço ao usuário final do ERP?

Não. O preço público aqui é o da API para o software parceiro. O valor cobrado do end-user pelo parceiro é decisão comercial do parceiro.
